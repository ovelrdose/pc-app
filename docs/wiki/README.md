# Вики: как работает «Сборщик»

Здесь описано, **как программа работает**: что она делает, как рассуждает, что происходит при каждом действии пользователя и как она реагирует на новые данные и правила. Модули, таблицы и API описаны в техническом документе [`../architecture.md`](../architecture.md).

> **Статус:** вики описывает целевое поведение системы. По мере реализации страницы сверяются с кодом. Если поведение реализовано иначе, правится вики, а не наоборот (см. `CLAUDE.md`, раздел «Вики»).
