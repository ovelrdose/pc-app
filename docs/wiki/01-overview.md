# 1. Обзор системы

## Что делает программа

«Сборщик» — экспертная система, которая подбирает комплектующие для ПК так, как это сделал бы опытный продавец-сборщик. Она:

1. **выясняет потребности**: задачи, бюджет, монитор, конкретные игры и программы, пожелания к внешнему виду, имеющиеся детали;
2. **формулирует требования**: какой класс видеокарты нужен, сколько памяти, как распределить бюджет;
3. **подбирает сборку** из каталога магазина с полной проверкой совместимости;
4. **балансирует** её, чтобы одна деталь не тормозила другие;
5. **прогнозирует производительность**: FPS в играх и результаты популярных бенчмарков;
6. **объясняет** каждое решение и отвечает на вопросы «почему не другая деталь?» и «потянет ли игру X?»;
7. **пересчитывает** сборку по просьбе клиента («видеокарту подешевле, а сэкономленное — в SSD»).

Главное отличие от фильтра в интернет-магазине: фильтр показывает товары, подходящие под галочки. Экспертная система **рассуждает** — учитывает сценарий использования, взаимосвязи деталей и бюджет — и может объяснить свой ход мысли.

## Кто пользуется

| Роль | Что делает в системе |
|---|---|
| **Клиент (гость)** | Проходит визард, получает три варианта сборки, правит их, задаёт вопросы «потянет ли», скачивает PDF. Регистрация не нужна |
| **Клиент (с аккаунтом)** | Всё то же, плюс сборки сохраняются в личном кабинете. После входа в аккаунт гостевые сборки переносятся туда |
| **Администратор каталога** | Добавляет и редактирует комплектующие, обновляет цены и наличие, загружает CSV/XLSX |
| **Инженер знаний** | Пишет и правит правила, ведёт справочники (игры, программы, сокеты, чипсеты), проверяет и публикует базу знаний |
| **Суперадмин** | Управляет пользователями и ролями |

## Из чего состоит система

```
┌───────────────────────── БАЗА ЗНАНИЙ ─────────────────────────┐
│  Фреймы                Правила (≥ 500)        Справочники      │
│  «что существует»      «как рассуждать»       игры, сокеты…   │
└────────────────────────────────────────────────────────────────┘
            │ опубликованный снимок                ▲ правит
            ▼                                      │ инженер знаний
┌──────────────── ЭКСПЕРТНОЕ ЯДРО ────────────────┐
│  Машина вывода ──► Конфигуратор ──► Прогноз FPS │◄── Каталог (≈300 деталей)
│        │                                        │        ▲ правит
│        └──► Трасса (журнал рассуждений)         │        │ админ каталога
└─────────────────────────────────────────────────┘
            │ сборки + объяснения
            ▼
┌──────────────── ИНТЕРФЕЙС ──────────────────────┐
│  Визард · Результаты · Сборка · Админка         │◄── клиент
└─────────────────────────────────────────────────┘
```

- **База знаний** — всё, что система «знает» о компьютерах: описания типов деталей (фреймы), правила рассуждения и справочные таблицы. Подробнее — [страница 2](02-knowledge.md).
- **Каталог** — конкретные товары магазина с характеристиками и ценами в рублях.
- **Экспертное ядро** — программа, которая применяет знания к ситуации клиента. Само ядро ничего не знает о компьютерах: оно умеет только исполнять правила. Поэтому систему можно «учить», не меняя код ([страница 3](03-inference-engine.md)).
- **Трасса** — журнал каждого шага рассуждения. Из неё строятся объяснения ([страница 6](06-explanations.md)).
- **Интерфейс** — то, с чем работают люди.

## Путь клиента в общих чертах

```
 Визард          Подбор               Результаты              Работа со сборкой
 ┌────────┐     ┌──────────────┐     ┌──────────────────┐    ┌──────────────────────┐
 │вопросы │ ──► │ядро рассуждает│ ──► │эконом/оптимум/max│ ─► │объяснения, правки,   │

 └────────┘     └──────────────┘     └──────────────────┘    └──────────────────────┘
                                                                     │ правка
                                                                     ▼
                                                              новая версия сборки
```

Полный пример с реальными шагами — на [странице 8](08-walkthrough.md).

## Какие задачи поддерживаются

Восемь сценариев. Клиент выбирает **основную** задачу и, если нужно, несколько **дополнительных** («в основном играю, иногда монтирую»):

| Сценарий | Что важно в железе |
|---|---|
| Офис | Минимальная цена, тишина, часто без отдельной видеокарты |
| Киберспорт (CS2, Valorant, Dota 2) | Высокий FPS → быстрый процессор (одно ядро), монитор 144–360 Гц |
| AAA-игры | Мощная видеокарта, видеопамять, разрешение монитора решает всё |
| 3D-рендер (Blender и др.) | Многоядерный CPU и/или мощная GPU, много памяти |
| Монтаж видео | Ядра CPU, ≥ 32 ГБ ОЗУ, быстрые SSD, аппаратное кодирование |
| Фото / графика / CAD | Одноядерная скорость CPU, объём ОЗУ |
| Программирование | Ядра для компиляции, много ОЗУ для виртуалок и Docker |
| Стриминг | Игра и кодирование видео одновременно |

Бюджет: **от 35 000 до 500 000 ₽**.

## Чего система не делает

- Не продаёт: корзины и оплаты нет, результат — сборка и PDF со спецификацией.
- Не подбирает периферию, мониторы и ОС. Монитор система спрашивает только для того, чтобы понять разрешение и частоту.
- Не обновляет цены сама: их обновляет администратор каталога ([страница 7](07-updates.md)).
- Не обучается сама на поведении клиентов: правила меняет только инженер знаний. Это классическая экспертная система, а не нейросеть.
