# Каталог комплектующих (CSV)

Один файл на категорию: `cpu.csv`, `motherboard.csv`, `ram.csv`, `gpu.csv`, `ssd.csv`, `hdd.csv`,
`psu.csv`, `case.csv`, `cpu_cooler.csv`, `case_fan.csv`. Колонки — слоты фрейма категории
(описаны в `backend/app/expert/frames/components.py` и отдаются API `GET /api/v1/frames`)
плюс сведения о цене.

Проверка без записи в БД: `cd backend && uv run python -m scripts.seed --dry-run`.

## Формат ячеек

| Что | Как писать | Пример |
|---|---|---|
| Число | точка как разделитель | `3.8` |
| Логическое | `true` / `false` | `true` |
| Список | через `\|` | `AM4\|AM5\|LGA1700` |
| Пустая ячейка | значение по умолчанию или «не заполнено» | |
| Цена | `price_rub` — целые рубли, пробелы допустимы | `18 990` |
| Дата проверки цены | `price_checked_at`, ГГГГ-ММ-ДД | `2026-10-29` |
| Источник цены | `price_note`, до 200 символов | `ориентир` |

Колонки `sku`, `brand`, `model`, `price_rub` обязательны. Неизвестная колонка отклоняет файл целиком.
Название (`name`) по умолчанию собирается из бренда и модели.

## Общие слоты всех категорий

`sku` (латиница в верхнем регистре, цифры, дефис), `brand`, `model`, `name`, `in_stock`
(по умолчанию `true`), `release_year`, `color` (`black`, `white`, `silver`, `gray`, `red`, `blue`,
`pink`, `other`), `rgb`.

## Соглашения по значениям

- Сокеты: `AM4`, `AM5`, `LGA1700`, `LGA1851`. Форм-факторы плат: `E-ATX`, `ATX`, `Micro-ATX`,
  `Mini-ITX`. Форм-факторы БП: `ATX`, `SFX`. Тип памяти: `DDR4`, `DDR5`.
- Разъёмы питания видеокарт и БП: `8-pin` (PCIe 6+2), `12V-2x6` (включая 12VHPWR). У БП
  перечисляется каждый разъём: `12V-2x6|8-pin|8-pin`.
- Объём RAM — объём всего комплекта, `modules` — число планок.
- `perf_single` — игровой/однопоточный индекс CPU, `perf_multi` — многопоточный, эталон Ryzen 5 7600
  = 100. `perf_raster` / `perf_rt` — индексы GPU, эталон RTX 4060 = 100. Значения стартового набора —
  оценки по открытым обзорам (Cinebench 2024, игровые тесты), уточняются на этапе 5.
- Без `perf_*` у CPU/GPU, длины у видеокарты, габаритов у корпуса и высоты у воздушного кулера
  позиция загружается со статусом `incomplete` и в подбор не попадает.

## Цены (стартовый набор, 2026-10-29)

- CPU — медиана предложений магазинов Москвы на price.ru.
- Видеокарты — медиана октября 2026 по магазинам (palert.ru); RX 9060 XT 8 ГБ — цена магазина.
- Материнские платы, RAM, SSD, HDD, БП, корпуса, охлаждение — сверены с price.ru 2026-10-29:
  - **медиана предложений магазинов Москвы без Ti-store**: у этого магазина цены систематически
    в 1,3–1,9 раза выше медианы остальных (например, Kingston NV3 1 ТБ — 23 490 ₽ при медиане
    14 910 ₽), поэтому он искажает медиану при 2–4 предложениях; медиана округляется до 10 ₽;
  - если предложений сейчас нет — «последняя цена» карточки price.ru (`price_note` это указывает);
  - если модель продаётся только в Ti-store или карточки на price.ru нет — цена остаётся оценкой
    (`ориентир; …` с причиной в `price_note`).
- Для кулеров с большим числом предложений (ID-Cooling SE-224-XTS, Deepcool AG400) медиана
  посчитана по первым 10 предложениям страницы.

## Расширение каталога (2026-10-30)

Каталог расширен со 103 до 251 позиции (+148 после сверки). Новые строки помечены `price_checked_at: 2026-10-30`.

- **Цены** — по тем же правилам price.ru (медиана магазинов Москвы без Ti-store, «последняя цена»
  при отсутствии предложений), в том числе для видеокарт. Модели подбирались по наличию: в первую
  очередь карточки с 2+ предложениями. Модели, у которых были только «последняя цена» или Ti-store
  (Ryzen 7 5700X3D, Crucial MX500/P3/P310, WD SN580, Corsair RM850, DeepCool CG560/LS720 и др.),
  в каталог не вошли. Исключения с «последней ценой»: Ryzen 9 7900, MSI MAG B650 TOMAHAWK WIFI,
  Gigabyte RX 9060 XT 16G GAMING OC.
- **Если у карточки несколько исполнений** (цвет, ревизия, ARGB), медиана считается по предложениям
  выбранного исполнения; исполнение указано в `model`.
- **Характеристики**, которых нет на price.ru, взяты из спецификаций производителей и карточек
  магазинов. 2026-10-30 поля, от которых зависит совместимость, сверены по открытым источникам
  (сайты производителей, спецификации у ритейлеров):
  - корпуса — размер, форм-факторы плат, длина видеокарты, высота кулера, вентиляторы в комплекте;
  - видеокарты — длина, толщина, разъёмы питания, рекомендованный БП;
  - кулеры — высота и рассеиваемая мощность;
  - спорные платы — число слотов памяти и M.2.

  Исправлено около 40 значений. Например: у DeepCool CH780 кулер до 132 мм, AN600 —
  низкопрофильный (67 мм), Ocypus Gamma C50 — корпус под Micro-ATX, у ASUS PRIME RX 9070 XT три
  разъёма 8-pin. Thermalright Macho Rev.B удалён: штатное крепление не подходит к AM5 и LGA1700.
  Где источники расходятся, взято значение производителя или более осторожное. Число слотов M.2,
  TBW и шум не сверялись построчно. У WD Red Plus 8 ТБ скорость записана как 5400 об/мин
  (фактически 5640, фрейм допускает 5400/5900/7200).
- **Индексы** `perf_*` новых CPU и GPU — оценки по открытым обзорам относительно эталонов
  (Ryzen 5 7600 = 100, RTX 4060 = 100), как и у стартового набора.
